# Cécilia — prototype Storytober

Prototype du site Cécilia, réalisé avec HTML, CSS et JavaScript.

## Fichiers
- `index.html` : page principale
- `style.css` : identité graphique
- `app.js` : fiches illustrées et mini-jeu de classement
- `heros.jpg` et `frimer.jpg` : deux illustrations fournies pour le prototype

## Publication avec GitHub Pages
1. Décompressez l'archive.
2. Dans votre dépôt GitHub `cecilia-storytober`, choisissez **Add file > Upload files**.
3. Déposez les cinq fichiers à la racine du dépôt.
4. Validez avec **Commit changes**.
5. Ouvrez **Settings > Pages**.
6. Choisissez **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
7. Attendez la publication et ouvrez l'adresse indiquée dans Settings > Pages.

Ce prototype ne contient que deux illustrations. Le classement complet et les liens TikTok seront ajoutés ensuite.
