LE PRINCIPE

Des prompts indépendants.
Un fil narratif à retrouver.

Les mots de l'Inktober n'étaient pas conçus pour former une chronologie. Ici, ils deviennent les fragments d'une même existence. Le numéro entre parenthèses rappelle l'ordre original du prompt ; le numéro principal indique sa place dans le récit.
